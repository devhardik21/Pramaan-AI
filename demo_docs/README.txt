# Pramaan AI — Document Test Pack

This pack contains fictional test documents for evaluating document upload, OCR, extraction, validation, duplicate detection and review workflows. The documents are not official AICTE forms, approvals, certificates, or records from real institutions.

## Files
- 01_application_form.pdf
- 02_permission_record.pdf
- 03_facility_certificate.pdf
- 04_institutional_undertaking.pdf
- 05_faculty_statement.pdf
- 06_faculty_details_addendum.pdf
- 07_infrastructure_evidence_register.pdf
- 08_laboratory_illustration.png
- 09_laboratory_illustration_duplicate.png

## Use
Upload the application form first, then supporting documents. Run OCR and validation, inspect extracted fields and review the evidence associated with any findings.

All institution names, identifiers, contacts, authorities and records are fictional. The illustration is not evidence of an actual facility.
